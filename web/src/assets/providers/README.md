# Subscription provider marks

Locally bundled provider brand marks, used decoratively without implying affiliation.
OpenAI and OpenCode reuse the SVG representations already used in `usage_dashboard`;
Command Code uses its published symbol, not the dashboard's former placeholder.

- **OpenAI Codex** (`openai-codex.svg`): OpenAI knot from `usage_dashboard/public/icons/codex.svg`. Official brand and trademark reference: https://openai.com/brand. OpenAI trademarks remain OpenAI's property.
- **OpenCode Go** (`opencode-go.svg`): OpenCode mark from `usage_dashboard/public/icons/opencode-go.svg`; official brand assets and guidance: https://opencode.ai/brand.
- **Command Code** (`command-code.svg`): official repository symbol: https://raw.githubusercontent.com/CommandCodeAI/command-code/refs/heads/main/.github/commandcode/symbols/symbol.svg, linked from https://commandcode.ai/brand. Its fixed colors are preserved as the brand guidelines require. Command Code marks remain their owner's property.
- **Neutral fallback** (`neutral.svg`): original generic glyph for unknown providers, not an official provider mark.

SVGs were checked to contain only local paths (no scripts, images, foreign objects, or external references). The namespace URL in SVG markup is the standard XML namespace, not a network dependency.
